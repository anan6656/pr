# PR profile 判定量化标准（v8.0.0）

本文档说明程序如何把识别出的柱轮廓量化为形貌量值、如何判定 profile。
**同一套量化同时供三处使用，口径完全一致**：单张图的结果图/统计、逐柱明细、
Baseline 对比（`pr_3.build_morphology` → `square_baseline` / `compare_morphologies`）。

---

## 1. 基准线：标准 CD = 柱子宽度出现最多的值（众数 CD）

- 每根柱逐行取宽度 W（右边界 − 左边界），做直方图，**取最高 bin 的中心**作为该柱的标准 CD；
  bin 宽 = max(0.5 nm, 5% × (P95 − P10))。
- 样本过少（<5 行）、分布恒定、或众数峰不突出（峰计数 < 1.5×中位 bin 计数）时回退中位数。
- 全图标准 CD 由所有纳入柱的行宽合并后同样取众数（`cd_mode_nm`）。
- **六类量值与分类阈值都以该众数 CD 为水平基准线**，不用平均 CD、不拟合柱身参考线。

## 2. 六类形貌量值（相对标准 CD 的宽度偏差，取 Q90 后与 0 取大）

先剔除定位坏行：宽度 < 0.5×CD 或 > 1.5×CD 的行不参与；同一区间内与中位宽偏离
> 0.35×CD 的行同样剔除。

| 类别 | 区间（相对高度 z） | 量值定义 |
|---|---|---|
| T-top | 顶部 z ≤ 18% | W − CD众数 的正偏差 Q90 |
| Top-rounding | 顶部 z ≤ 20% | 相对锥度线的亏缺 Q90 的一半（**单侧深度**，见第 3 节） |
| 中间粗 | 中段 35% ~ 65% | W − CD众数 的正偏差 Q90 |
| 中间细 | 中段 35% ~ 65% | max(CD众数 − W 的正偏差 Q90, **底部宽 − 中段宽**) |
| Footing | 底部 z ≥ 82% | W − CD众数 的正偏差 Q90 |
| Undercut | 底部 z ≥ 82% | CD众数 − W 的正偏差 Q90 |

> **中间细为何加“底部宽 − 中段宽”**（v7.5.0）：人工判断中间细看的是柱身比柱脚细
> （锥形柱，A4CD536 中段 8.72 vs 底部 10.46、A52Q193 19.51 vs 23.34）。只以众数 CD
> 为基准时，锥形柱的柱身与 CD 接近，该信号仅 0.1nm 级，低于阈值会漏报。
> 不把“中段 − 顶部”对比计入中间粗：SEM 圆头柱顶部天然窄于柱身（A4BY067 2.8nm、
> A63Q162 系 5nm+），会把正常圆顶柱误报为中间粗。

## 3. Top-rounding 的三种口径（v6.6 起）

| 字段 | 含义 | 用途 |
|---|---|---|
| `top_rounding_nm` | **顶部圆角亏缺深度（单侧）** | **判定主量**，与其余五类同量级可比 |
| `top_rounding_pct` | 深度 ÷ 众数 CD（%） | 跨 CD 样本对比的辅助量 |
| `top_rounding_r_nm` | 等效圆角半径 √(A /(2(1−π/4))) | 旧口径，仅作参考导出 |

**为什么改口径**：旧口径用"缺失截面积开方"换算半径，会把 2 nm 的顶部亏缺放大到
5 nm 量级，数值远大于其余五类的宽度偏差，且半径名义值与肉眼看到的"顶部圆掉多少"
不符。现主量直接是**单侧壁相对锥度线收缩了多少 nm**。

**锥度扣除**：先用中段（z 35%~65%）线性拟合侧壁斜率外推到顶部区，只把**超出锥度线
的额外亏缺**计为圆角——纯梯形/锥形柱的顶部收窄是锥度，不算圆角；外推锥度线以帽区
最大观察宽封顶，避免把整帽收窄误计为圆角。

## 4. 判定阈值

```
σ_noise   = 各纳入柱"宽度相邻行差分 std/√2"的中位数（剔除断行缺口对）
shape_thr = max(1.0 nm, min(4.0 × σ_noise, 6.0 nm))       # 自适应阈值带上下限
生效阈值  = max(shape_thr, 比例 × 众数 CD)
```

比例分三类：

| 比例 | 取值 | 适用 |
|---|---|---|
| 通用 `MORPH_SHAPE_CD_RATIO` | 0.10 × CD | T-top / Undercut |
| 分类别 `MORPH_SHAPE_CD_RATIO_BY_KEY` | top_rounding 0.30 × CD、footing 0.12 × CD | 这两类单独加严 |
| 结构性对比 `middle_thin/middle_thick` | max(1nm, 0.12 × CD) | 不用 σ 自适应项 |

**依据**（grey_images 人工标注集标定，10 张，hit 9/10、主标签 8/10，normal 三张零误报）：
- 正常圆顶工艺柱的圆化随 CD 等比缩放，实测深度 0.05~0.24 × CD，属正常柱形而非缺陷；
- 真实 footing 实测 0.26~0.29 × CD，而柱底渐变吸附/衬底亮带造成的假阳性约 0.12 × CD；
- 中间细的“中段 vs 底部”是结构性信号，不随行噪声缩放；σ 自适应项会把小柱图的真实
  中间细卡掉（A4CD536 1.73nm vs σ 项 2.14nm），故该类只用下限 + CD 比例。

**v7.1.0 起不再计算周期起伏（幅值/周期）与驻波分类**：该量由侧壁频谱拟合得到，
受单包络形貌与噪声影响大，不作为形貌判据；粗糙度只保留 LER/LWR 3σ。

## 5. 多标签与星级

- 整图（平均轮廓）取**超生效阈值的量值降序前二**作标签，如 `Footing+Undercut`；
  0 个超阈值 → **Normal**。逐柱仍是互斥单标签。
- 星级只评主标签量值：≥3× 生效阈值 ★★★、≥2× ★★、≥1× ★，否则 0。
- 结果图顶部横幅显示 `Profile: 主标签+第二标签 ★★ · 各类柱计数`。

## 6. Baseline 对比是否同一量化

是。`square_baseline(CD, H)` 生成理想方波后**走同一个 `build_morphology`**：
方波的六类量值全为 0、分类 Normal、CD = 设定值；样本侧同样由 `build_morphology`
产出，逐项做 Δ 与变化率对比（粗糙度类取逐柱原始采样均值，其余取平均坐标轮廓）。
新增指标（如 `top_rounding_pct`）由 `MORPHOMETRY` 表统一驱动，两侧自动同步，无硬编码。

## 7. 识别层的边界定位（v7.1.0~v7.5.0）

量化与判定依赖边界精度，识别层按以下顺序处理（都在收缩守卫之后）：

1. **断行填补**：柱体纵向追踪丢行时按邻行线性插值补齐（缺口 > max(4, 20%×柱高) 不补）。
2. **粘连宽柱拆分**：宽度 > 1.7×柱群中位的柱，在柱高方向统计列中位灰度，找两侧为
   柱体、中间明显变暗且宽 2~10px 的**纵向暗缝**，在缝中心一分为二（A671318-01M-2）。
3. **碎片柱合并**：宽度 < 0.45×中位宽且与邻柱间隙 ≤3px 的窄条并入邻柱（防柱被切碎）。
4. **无效结构剔除**：柱高 > 40% 图高的"柱"视为衬底/通孔长结构；全剔后保留最合理的
   一根（A575082 via 图由 9 根收敛为 1 个孔）。
5. **柱底共识延伸**：高于柱群共识底边 max(3px, 10%×柱高) 的柱底向下延展到共识位置，
   自带逐行灰度证据校验（不拖尾进衬底）。

评估指标（不看图的数值化验收）：边界梯度对齐度 align（边界点与横向梯度峰值的偏移）、
顶/底边界面证据 topR/botR、柱宽/柱高变异系数、断裂率 gap。
当前全量：align 0.762、CDcv 0.055、GT 命中率 9/10、主标签 8/10；人工 normal 三张零误报。

## 8. 横向亮带惩罚（v8.0.0）

主体带（柱区）选择时，"亮于行内中位"掩码的**最大连续亮段宽度占比 ≥50%** 的行
按占比线性压低活动度（最低 0.25）：横向电极条、SEM 信息栏、连片亮层的行内亮段
横跨大半个行宽，不是柱结构，防止主段被它们抢占。柱区每行是多个分离亮块
（单孔/单柱图占比也远低于 50%），不受影响。
粘连宽柱拆分触发条件为 1.5×柱群中位宽；**找不到可靠纵向暗缝则不拆**
（实测 A671318-01M-2 的 60~64px 宽柱内部无暗缝，是单柱而非粘连；
放宽到 1.15× 会误拆 A671318-01M-4 的 48px 单柱，故维持 1.5×）。
