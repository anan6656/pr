# pr7.0 — PR profile analyzer 代码目录

`pr7.0/` 根目录始终保存**当前最新**的代码，本工作空间每完成一次改动即整体覆盖上传；
每次更新同时在 `pr7.0/` 下新增一个小版本文件夹（v6.6、v7.0.1、v7.1.0、v7.5.0、v8.0.0 …）
保存该次快照，便于回退与对比。

| 文件 | 职责 |
|---|---|
| `pr_1_config.py` | 全局配置：常量、形貌指标定义、阈值、比例尺读写；`parse_ground_truth` / `param_overrides` |
| `pr_2_image_recognition.py` | 图像识别管线：预处理、柱检测、边界精修；`process_image` / `analyze_image` |
| `pr_3_contour_calc.py` | 轮廓量化：六类形貌量值、`build_morphology`、分类与星级、结果图渲染 |
| `pr_4_contour_compare.py` | Baseline 对比图与报告导出 |
| `pr_5_gui.py` | GUI 主界面（含直线量测实时灰度曲线、Baseline 三联图） |
| `pr_6_main.py` | 主入口：启动 GUI / `--build-exe` 离线打包 |
| `pr_8_profile_validation.py` | 测试工具：标注集验证、参数扫描、报告（生产逻辑在 pr_1~pr_3） |
| `grey_text.py` | 灰度文本 ↔ TIF 互转（`--batch` 多文件转子文件夹、`--depth`、`--verify`） |
| `PR_profile_判定量化标准.md` | 判定量化标准说明（标准 CD、六类量值、Top-rounding 口径、阈值、识别层边界定位） |

## v8.0.0（2026-10-21）

**版本号 8.0.0**，打包产物 `PR_profile_analyzer_v8.0.0.exe`。

- **横向亮带惩罚**：主体带选择时，"亮于行内中位"掩码的最大连续亮段宽度占比 ≥50% 的行
  按占比线性压低活动度（最低 0.25），防止主段被横向电极条/信息栏/连片亮层抢占。
- **粘连拆分阈值回归 1.5×中位宽**并补"无暗缝不拆"验证：实测 A671318-01M-2 的 60~64px
  宽柱内部无纵向暗缝，是单柱而非粘连（放宽到 1.15× 会误拆 A671318-01M-4 的 48px 单柱）。
- 修复 `positive_q90` 区间为空返回 None 导致 `max(float, None)` 崩溃
  （AYX3456JB_PEB110C_-0.06um 实测）。
- 判定与识别最终指标：grey_images 标注集 **hit 9/10、主标签 8/10**；人工 normal 三张
  **零误报**；多标签最多两种；align 0.762、柱宽 CV 0.055、底边证据 1.66。
- 唯一未命中 A575082（via 单孔，GT undercut）：孔的底部收缩仅 0.23nm，与人工判读
  依据不同；该图已按"只识别 1 个孔"输出（PR1 y174-396）。
