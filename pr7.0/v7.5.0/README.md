# pr7.0 — PR profile analyzer 代码目录

`pr7.0/` 根目录始终保存**当前最新**的代码，本工作空间每完成一次改动即整体覆盖上传；
每次更新同时在 `pr7.0/` 下新增一个小版本文件夹（v6.6、v7.0.1、v7.1.0、v7.5.0 …）
保存该次快照，便于回退与对比。

| 文件 | 职责 |
|---|---|
| `pr_1_config.py` | 全局配置：常量、形貌指标定义、阈值、比例尺读写；`parse_ground_truth` / `param_overrides` |
| `pr_2_image_recognition.py` | 图像识别管线：预处理、柱检测、边界精修；`process_image` / `analyze_image` |
| `pr_3_contour_calc.py` | 轮廓量化：六类形貌量值、`build_morphology`、分类与星级、结果图渲染 |
| `pr_4_contour_compare.py` | Baseline 对比图与报告导出 |
| `pr_5_gui.py` | GUI 主界面（含直线量测实时灰度曲线、Baseline 三联图） |
| `pr_6_main.py` | 主入口：启动 GUI / `--build-exe` 离线打包 |
| `pr_8_profile_validation.py` | 测试工具：标注集验证、参数扫描、报告（生产逻辑在 pr_1~pr_3） |
| `grey_text.py` | 灰度文本 ↔ TIF 互转（`--batch` 多文件转子文件夹、`--depth`、`--verify`） |
| `PR_profile_判定量化标准.md` | 判定量化标准说明（标准 CD、六类量值、Top-rounding 口径、阈值、识别层边界定位） |

## v7.5.0（2026-10-21）

**版本号 7.5.0**，打包产物 `PR_profile_analyzer_v7.5.0.exe`。

- **中间细新增“中段 vs 底部宽”判据**（向人工判断靠近）：人工看中间细是柱身比柱脚细，
  锥形柱 A4CD536 中段 8.72 vs 底部 10.46；只以众数 CD 为基准时该信号仅 0.1nm 级会
  漏报。中间细 = max(相对 CD 收缩, 底−中)；中间粗不变（不把“中段−顶部”计入：
  SEM 圆头柱顶部天然窄，会把正常圆顶柱误报为中间粗）。
- **中间细/粗改用结构性门槛** max(1nm, 12%×CD)，不用 σ 自适应项——σ 项把小柱图的
  真实中间细卡掉（A4CD536 1.73 vs σ 项 2.14）。
- **效果**：grey_images 标注集 hit **9/10**、主标签 8/10（v7.1.0 为 8/10 / 8/10）；
  人工判 normal 的三张（A4BY067、A63Q162-24-2/-6）**全部零异常**；多标签仍最多两种。
- 文档与代码同步：形貌定义、ABOUT/PROFILE 帮助、判定标准文档全部更新到 v7.5.0
  （删除周期起伏/驻波描述，补识别层边界定位章节）。
- 识别指标无退化：align 0.761、柱宽 CV 0.055、底边证据 1.66。
